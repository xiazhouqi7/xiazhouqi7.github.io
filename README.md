## What lives here

This repository powers the Xiazhouqi brand homepage and acts as the public entry point for:

- **Xiazhouqi Clear** — restrained, information-first interface design
- **Xiazhouqi Warm** — soft, warm and personal visual design
- **Xiazhouqi Photography** — photography, color grading and visual storytelling
- selected web tools and personal projects

## Design direction

The site uses **Clear as the structural foundation** with a small amount of **Warm** for atmosphere. The goal is calm hierarchy, generous spacing, mobile reliability and low visual noise.
